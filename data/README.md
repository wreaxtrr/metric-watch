# Сохранённые данные

`wikimedia.csv`: дневные просмотры трёх страниц английской Wikipedia,
2025-01-01 — 2025-06-30 включительно, UTC. Ключ строки — `(series, date)`.
`value` — число просмотров, не уникальных пользователей.

`wikimedia.source.json` содержит URL запросов, момент загрузки и параметры.
Источник: Wikimedia Analytics API, категория агента `user`, все способы доступа.
Это агрегированная открытая статистика; индивидуальные события не загружались.

Лицензия данных: CC0 1.0, согласно
https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/documentation/access-policy.html

В файле нет разметки аномалий. Синтетические инциденты используются только
в отдельном эксперименте `python monitor.py demo`.
